# Student Registration Form

A responsive student registration form built with HTML, CSS, and vanilla JavaScript.

## Run
1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Try submitting the empty form to see field-specific validation messages.
4. Complete all fields using a Philippine mobile number in the format `09XXXXXXXXX`.
5. Submit to see the success message. Use Reset Form to clear the form.

## Included concepts
- Submit event, Event Object, and `event.preventDefault()`
- `trim()`, email and phone validation, password confirmation
- Field-specific error messages and `.error` class handling
- `classList.add()`, `classList.remove()`, and `classList.toggle()`
- `data-required`, `data-label`, and `dataset`
- Dynamic `max` attribute on Date of Birth and password `type` attribute
- Success and reset behavior
